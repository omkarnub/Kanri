1. Getting Started with Kanri

Learn how to install the verified release APK, handle Android 13+ restricted settings, configure permissions, and complete initial onboarding.

1. Downloading & Verifying the APK

Always obtain the Kanri APK from the official GitHub release assets. Never install from unverified third-party mirror portals.

  • Current Release: v1.19.8 (Build 75)
  • Minimum Android Requirement: Android 8.0 Oreo (API level 26) or newer
  • SHA-256 Checksum: 34DF85A3EAD322E65BC46CB2C7AB30F2D8FBD682289CBA24740C05C3E47C7538
# Verify SHA-256 in terminal
# Windows (PowerShell):
Get-FileHash Kanri-v1.19.8-release.apk -Algorithm SHA256

# macOS / Linux:
shasum -a 256 Kanri-v1.19.8-release.apk

2. Sideloading & Android 13+ "Restricted Settings"

When you install an APK outside the Google Play Store on Android 13, 14, or 15, Android protects sensitive listeners by greying out Notification Listener permissions. To enable automatic transaction capture:

  1. Install the APK and open Kanri.
  2. When navigating to the permissions grant screen, Android may alert: "Restricted setting: For your security, this setting is currently unavailable."
  3. Open your device's Settings app.
  4. Navigate to Apps > All Apps > Kanri.
  5. Tap the three dots menu (⋮) in the top-right corner.
  6. Tap Allow restricted settings.
  7. Authenticate using your biometric fingerprint or device PIN.
  8. Return to Kanri: you can now toggle Notification Listener access.

3. Recommended Permissions Configuration

Permission Status Impact if Denied
RECEIVE_SMS / READ_SMS Recommended Bank debit and credit alerts cannot be parsed automatically. Kanri operates in manual entry mode.
Notification Listener Recommended UPI payment app merchant names (GPay, PhonePe, Paytm, CRED) cannot be extracted to enrich transactions.
SYSTEM_ALERT_WINDOW Optional The 1-tap floating category chip after in-store payments will not appear. You can still categorize in-app.
Biometric Lock Optional App opens immediately without biometric prompt screen-off authentication.

4. Initial Onboarding Flow

When opening Kanri for the first time:

  1. Interactive Brand Intro: Staggered Panchang kinetic typography animation. Tap to skip.
  2. Wallet Baseline: Enter your current Cash and Online bank balance to calibrate starting net worth.
  3. Budget Cycle Date: Select your salary credit day (e.g., 1st, 5th, or 25th) so spending pacing tracks your actual monthly pay cycle.
  4. Theme Selection: Choose your default theme: Light (Cream), Dark (Ink), AMOLED, System, or Glass.
